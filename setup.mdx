---
title: "Instalação"
description: "Como instalar dependências e rodar o projeto."
---

```bash
npm install
npx expo start
```

## Scripts

| Comando | Descrição |
| --- | --- |
| `npm start` | Inicia o servidor de desenvolvimento do Expo |
| `npm run android` | Executa no Android |
| `npm run ios` | Executa no iOS |
| `npm run web` | Executa na Web |
| `npm run lint` | Executa o ESLint |
| `npm run fix-deps` | Corrige as dependências do Expo |

## Permissões

- **iOS:** localização (Tap to Pay), Bluetooth (leitores de cartão) e NFC.
- **Android:** NFC e localização precisa.
