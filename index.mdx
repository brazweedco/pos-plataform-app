O BrazWeed POS é um aplicativo de ponto de venda para iOS, Android e Web.

## Stack

- Expo SDK 54 com Expo Router v6
- TypeScript
- React Native 0.81 e React 19
- Zustand para estado e TanStack React Query para dados
- Stripe React Native e Stripe Terminal (Tap to Pay)
